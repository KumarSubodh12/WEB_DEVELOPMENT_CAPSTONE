# 🛒 Online Marketplace System (ShopX)

A full-stack E-Commerce Web Application built using Flask, SQLite, HTML, CSS, and Bootstrap.  
Inspired by modern platforms like Myntra & Amazon.

---

## 🚀 Features

### 👤 User Features
- User Authentication (Login / Register)
- Browse Products
- Search Products
- Add to Wishlist
- Add to Cart
- Place Orders
- View Order History

### 🧑‍💼 Admin Features
- Add Products (with image upload)
- Edit Products
- Delete Products
- Manage inventory

### 🎨 UI/UX
- Sidebar Navigation (Dashboard, Cart, Orders, Wishlist, Admin)
- Responsive Layout
- Clean Myntra-style UI
- Hover Effects on Products
- Flash Messages

---

## 🛠️ Tech Stack

- Backend: Flask (Python)
- Database: SQLite (SQLAlchemy)
- Frontend: HTML, CSS, Bootstrap
- Authentication: Flask-Login
- Security: Werkzeug Password Hashing

## ⚙️ Installation & Setup

1. Clone the repository

git clone https://github.com/your-username/shopx.git
cd shopx

2. Install dependencies

pip install flask flask_sqlalchemy flask_login

3. Run the application

python app.py

4. Open in browser

http://127.0.0.1:5000/
